# Blood Donation System Frontend

This frontend is built with React, Vite, and Tailwind CSS.

## Tech Stack

- React for the user interface
- Vite for development and production builds
- Tailwind CSS for styling
- React Router for navigation
- React Icons and Lucide React for icons

## Scripts

```powershell
npm install
npm run dev
npm run build
npm run lint
```

Set `VITE_API_URL` when the backend is deployed on a separate domain.
